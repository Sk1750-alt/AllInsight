About the project

Built to be fast, and honest.

AllInsight is a desktop application written in Rust and TypeScript on Tauri 2. These are the decisions behind it.

Architecture

Three layers, one direction.

The window renders state and collects intent. Every decision that matters is made in Rust.

The window React · TypeScript

Renders state and collects intent. Holds no privilege, and makes no decision that matters. A buggy or compromised interface cannot delete anything.

React 19TypeScriptTailwindRadix UISVG charts
Tauri IPC, typed both sides

Commands deliberately thin

Validate the arguments, call exactly one service, return data. No logic lives here.

Engineering

Measured, then made faster.

A timing probe found the live monitor blocking the window for 184.6 ms on every tick. It now takes 25.3 ms, and the slow commands moved off the window's thread entirely.

Decisions

Small choices, made carefully.

I

A scanner that never stalls

Parallel through rayon, cancellable at any moment, and tolerant: a folder it cannot read is counted and skipped, never fatal. Links are recorded, not followed.

II

Unknown, not Healthy

When a drive will not report its wear, the verdict is Unknown, with a reason. Windows having no complaint is not the same as the drive being well.

III

Charts drawn by hand

Simple SVG shapes that match the palette exactly, rather than a charting library that ships its own theme to fight with.

IV

Errors written for people

Messages are written to be shown as they are. A screen that fails never takes the window with it.

V

A quiet background monitor

It never walks the file system, so its cost stays flat however many files you have. Passing two thresholds at once sends one message, not two.

VI

Tested where it matters

Path traversal, protected paths, junction and symlink refusal, the deletion guard, and duplicates that differ only in the middle of the file.
