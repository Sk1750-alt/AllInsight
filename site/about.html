About the project

Built to be fast, and honest.

Rust and TypeScript, on Tauri 2.

Architecture

Three layers, one direction.

The window React · TypeScript

Renders state and collects intent. Holds no privilege, and makes no decision that matters. A buggy or compromised interface cannot delete anything.

Tauri IPC, typed both sides

Commands deliberately thin

Validate the arguments, call exactly one service, return data. No logic lives here.

one call each

Services Rust

Security, storage, cleanup, system, processes, health, battery, applications, startup, AI and the database. All the actual work.

Windows or Linux

Your operating system read, rarely written

Win32, WMI, the registry and the file system on Windows; sysfs, D-Bus, UDisks2 and XDG on Linux.
