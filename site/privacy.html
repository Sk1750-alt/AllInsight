Private by design

Nothing leaves
your computer.

Not as a setting. As an absence of code. AllInsight has no account, no update checker, no analytics and no cloud service.

How it is kept private

Three properties, built in.

I

No route out

There is no HTTP client in the application capable of reaching a remote host. The one that exists is compiled without TLS and only ever pointed at a loopback port.

II

No update checker

AllInsight never phones home, not even to ask whether a new version exists. You decide when to update, from this site.

III

The model stays local

The optional AI runs as a separate process bound to 127.0.0.1. AllInsight never downloads a model; there is no download code in the binary.

The proof

Pull the cable.
Nothing changes.

Disconnect the machine and every screen behaves identically. AllInsight shows "Offline mode - all local features available" rather than an error, because offline is not an error. It is the design.

What is kept

Totals, never contents.

AllInsight keeps one small database on your own disk, so it can show trends and history. This is everything it holds, and everything it refuses to.

Permissions

An ordinary user, by default.

AllInsight never asks for administrator rights at launch. All user-scoped cleanup, the storage map, duplicate detection, process management and per-user startup entries work without elevation.

On Linux it never runs as root at all: everything it cleans belongs to you, and drive health comes from UDisks2 without privilege.

On Windows, three exceptions

Drive wear on SATA drivesWindows only lets an elevated process read those counters. NVMe drives report without it.
Windows Update cleanupThose folders belong to the system.
Machine-wide startup entriesThey live in the machine's part of the registry.

Each one says so where it matters. Without elevation, drive health reads Unknown, with an explanation. Never a guess.
