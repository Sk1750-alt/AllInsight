The method

Measure. Explain.
Then, and only then, clean.

  1. I

    Measure everything.

    A parallel scan maps every folder on the drive, and every file lands in a category you recognise. Links are never followed, so nothing is counted twice.

  2. II

    Explain it plainly.

    Every recommendation comes with the measurement behind it. Where the hardware is silent, AllInsight says Unknown instead of guessing.

  3. III

    Clean only what regrows.

    Caches and temporary files, after a dry run and a confirmation that lists exactly what will and will not be touched. Your documents are never candidates.

The safety model

Eight checks.
In order. Every time.

The interface never sends a file path to a destructive command. Removal needs a token only the deletion guard can issue, and the last five checks run at the moment of deletion, not when the preview was built.

  1. Collapse .. and . so a path cannot sneak past the list
  2. Refuse the protected list: the system, your folders, your credentials
  3. Refuse anything outside the category's own folders
  4. Confirm it still exists, without following links
  5. Refuse it if it is itself a link or junction
  6. Refuse it if any folder above it is one
  7. Resolve the real path, and run checks two and three again
  8. Confirm it is still what the scan recorded

Never part of a cleanup

Documents · Desktop · Pictures · Videos · Music · Downloads · Source code · Databases · Browser profiles · Saved passwords · The operating system
