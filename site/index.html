The method

Measure. Explain.
Then, and only then, clean.

  1. I

    Measure everything.

    A parallel scan maps every folder on the drive, and every file lands in a category you recognise. Links are never followed, so nothing is counted twice.

  2. II

    Explain it plainly.

    Every recommendation comes with the measurement behind it. Where the hardware is silent, AllInsight says Unknown instead of guessing.

  3. III

    Clean only what regrows.

    Caches and temporary files, after a dry run and a confirmation that lists exactly what will and will not be touched. Your documents are never candidates.
