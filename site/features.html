Duplicates

Matched by content. Never by name.

Three passes, each cheaper than the next is expensive: group by exact size without opening a file, hash the first and last 64 KB, then hash in full only what survives. Two files match only when every byte does.

On Linux

Native on Linux, never as root.

Everything AllInsight cleans belongs to you, and drive health comes from UDisks2 without privilege.

ScreenWhere it reads from on Linux
CleanupYour own files only: the temporary folder, thumbnail, font and shader caches, browser caches (Chrome, Chromium, Edge, Brave, Vivaldi, Opera, Firefox including Snap) and the freedesktop Trash.
ApplicationsThe desktop entries your launcher shows, traced to dpkg, rpm, pacman, Flatpak or Snap. For system packages it shows the exact command, because it never runs a package manager as root.
StartupXDG autostart. Disabling writes a per-user Hidden=true override, exactly as GNOME and KDE do.
Drive HealthUDisks2 over D-Bus: SMART failure prediction, temperature, power-on hours, bad sectors and NVMe warnings, falling back to sysfs.
Battery/sys/class/power_supply
GPU/sys/class/drm, amdgpu busy counters, and nvidia-smi when present.
ProcessesRefuses to end init, the compositor, the display server and the session bus. Ends processes with SIGTERM, not SIGKILL.
