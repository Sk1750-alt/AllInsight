# Code of Conduct

AllInsight is built by people with different backgrounds, languages and levels of experience. We want everyone to feel welcome here.

## Expected behaviour

- Be respectful and patient, especially with newcomers and people writing in a second language.
- Critique code and ideas, not people.
- Assume good intent, and ask before assuming.
- Accept decisions gracefully, even when you disagree.

## Not acceptable

- Harassment, insults, slurs, or personal attacks.
- Unwelcome sexual attention or content.
- Discrimination of any kind.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.

## Scope

This applies in all project spaces: issues, pull requests, discussions, chat channels, and events, and when someone represents the project in public.

## Reporting

Report problems by opening a private report via GitHub or emailing the maintainer directly. Reports are handled confidentially. If a maintainer is involved, they will step aside from handling the report.

## Enforcement

Maintainers may respond with a warning, temporary restriction, or permanent ban from project spaces, depending on severity and history.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
